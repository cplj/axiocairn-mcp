# axiocairn

Connection details for the **Axiocairn MCP server**, a hosted service that lets AI agents retrieve published market research reports, their data dates and their limitations.

This package contains no server code and no research content. Run `axiocairn` to print the endpoint and the connection guide.

- Endpoint: https://axiocairn.com/mcp (Streamable HTTP, account authorization)
- Connection guide: https://axiocairn.com/en/assistant
- Documentation and releases: https://github.com/cplj/axiocairn-mcp

Axiocairn publishes research information, not investment advice.
