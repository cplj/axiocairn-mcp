# Contributing

This repository holds documentation and connection metadata for the hosted Axiocairn MCP server. It does not contain the server code, so changes here cover README text, `server.json`, `mcp.json`, `llms.txt`, the docs page and the translations.

## Good contributions

- A broken or outdated link, or a setup step that no longer matches the client.
- A client configuration you tested yourself. Say which client and version, the date, and what happened.
- A translation as `README.<code>.md`. Keep every number, date and condition the same as the English file.
- A clearer sentence. Shorter is better.

## Ground rules

- Mark a client as verified only when you connected it, authorized an account and got answers on a stated date. A template is not a verification.
- No credentials, tokens, account details or restricted report content in issues, pull requests or examples.
- No performance, accuracy or investment claims. Describe what the tool returns and where it stops.
- Show the data date next to any number taken from a report.
- Documentation is in English; Traditional Chinese lives in `README.zh-Hant.md`.

## Sending a change

1. Open an issue first for anything larger than a typo, so we can agree on scope.
2. Fork, make one focused change, and open a pull request using the template.
3. Keep `README.md` and `README.zh-Hant.md` in step when you change a fact.

Server bugs, access problems and report questions go to [contact@axiocairn.com](mailto:contact@axiocairn.com). Security reports follow [SECURITY.md](SECURITY.md).
