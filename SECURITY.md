# Security

Report suspected vulnerabilities privately to contact@axiocairn.com.

Include the affected public URL, a short description, the time with time zone, and minimal reproduction steps. Redact account details and credentials. Do not include report content that you do not have permission to share.

Do not post credentials, personal information, or access to restricted reports in a public issue. Do not test against other accounts or disrupt the hosted service.

This repository contains documentation and connection metadata. Account authorization and access controls belong to the hosted service. Revoke unwanted connections from your Axiocairn account.
