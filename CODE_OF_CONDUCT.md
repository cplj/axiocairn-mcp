# Code of Conduct

We want this project to be a place where people can ask plain questions and get plain answers.

- Be courteous. Disagree with the idea, not the person.
- No harassment, insults, discrimination or personal attacks.
- Do not share other people's private information.
- Keep discussion on the repository's documentation and connection metadata.

Maintainers may edit, hide or remove comments, issues and pull requests that break these rules, and may block repeat offenders.

To report a problem, write to [contact@axiocairn.com](mailto:contact@axiocairn.com). Reports are read privately.

This text is adapted in spirit from the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
